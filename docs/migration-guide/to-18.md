# Migrating to 18.0.0

This release contains breaking changes.

## Breaking changes

We've removed:

- support for end-of-life and older versions of Node.js
- `*syntax` options from `declaration-property-value-no-unknown`

And changed:

- `globbyOptions` option to `globOptions`

### Removed support for end-of-life and older versions of Node.js

We've removed support for Node.js versions less than 22.18.0, 24.3.0 and 26.0.0, including end-of-life 20.x, 23.x and 25.x, to update all our dependencies.

We recommend updating to the latest version of Node.js.

### Removed `*syntax` options from `declaration-property-value-no-unknown`

We've removed the `propertiesSyntax` and `typesSyntax` options from [`declaration-property-value-no-unknown`](../../lib/rules/declaration-property-value-no-unknown/README.md) that we [deprecated in 17.5.0](../../CHANGELOG.md#1750---2026-03-19).

You should update your config to use the shared and more performant [`languageOptions`](../user-guide/configure.md#languageoptions) configuration property instead:

```diff json
{
+ "languageOptions": {
+   "syntax": {
+     "properties": { "top": "| <--foo()>" },
+     "types": { "--foo()": "--foo( <length-percentage> )" }
+   }
+ },
  "rules": {
    "declaration-property-value-no-unknown": [
      true,
-     {
-       "propertiesSyntax": { "top": "| <--foo()>" },
-       "typesSyntax": { "--foo()": "--foo( <length-percentage> )" }
-     }
    ]
  }
}
```

### Changed `globbyOptions` option to `globOptions`

We've replaced the `globbyOptions` option and its `--globby-options` flag with `globOptions` and `--glob-options`, so that the library we use to match files is an implementation detail rather than part of our API.

The new option supports only `dot`. Stylelint will throw a configuration error for any other option, for example:

```console
Invalid globOptions configuration: unknown option "cwd". Supported options: "dot".
```

You should rename the option in your Node.js API calls:

```diff js
const result = await stylelint.lint({
  files: "**/*.css",
- globbyOptions: { dot: true }
+ globOptions: { dot: true }
});
```

And rename the flag in your scripts. The `--go` short flag is unchanged:

```diff shell
-stylelint "**/*.css" --globby-options '{"dot":true}'
+stylelint "**/*.css" --glob-options '{"dot":true}'
```

If you used other globby options, you should replace them:

- `cwd` with the top-level [`cwd`](../user-guide/node-api.md#cwd) option, which relative globs are now resolved from
- `ignore` with negated globs in `files`, e.g. `"!**/vendor/**"`, or the `ignorePattern` option ([`--ignore-pattern`](../user-guide/cli.md#--ignore-pattern---ip) on the CLI)
- `gitignore` with the [`ignorePath`](../user-guide/options.md#ignorepath) option pointing at your `.gitignore` file

Other options, such as `followSymbolicLinks` and `deep`, no longer have an equivalent.
