# Migrating to 18.0.0

This release contains breaking changes.

## Breaking changes

We've removed:

- support for Node.js less than 22.18.0 and EOL versions

### Removed support for Node.js less than 22.18.0

To update all our dependencies, we've removed support for Node.js versions less than 22.18.0 and end-of-life versions: 20.x, 23.x and 25.x

We recommend updating to the latest version of Node.js.
