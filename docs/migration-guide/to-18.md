# Migrating to 18.0.0

This release contains breaking changes.

## Breaking changes

We've removed:

- support for end-of-life and older versions of Node.js
- `*syntax` options from `declaration-property-value-no-unknown`

And changed:

- TypeScript config files to be loaded by Node.js's built-in type stripping

### Removed support for end-of-life and older versions of Node.js

We've removed support for Node.js versions less than 22.22.2, 24.15.0 and 26.0.0, including end-of-life 20.x, 23.x and 25.x, to update all our dependencies.

We recommend updating to the latest version of Node.js.

### Removed `*syntax` options from `declaration-property-value-no-unknown`

We've removed the `propertiesSyntax` and `typesSyntax` options from [`declaration-property-value-no-unknown`](../../lib/rules/declaration-property-value-no-unknown/README.md) that we [deprecated in 17.5.0](../../CHANGELOG.md#1750---2026-03-19).

You should update your config to use the shared and more performant [`languageOptions`](../user-guide/configure.md#languageoptions) configuration property instead:

```diff json
{
+ "languageOptions": {
+   "syntax": {
+     "properties": { "top": "| <--foo()>" },
+     "types": { "--foo()": "--foo( <length-percentage> )" }
+   }
+ },
  "rules": {
    "declaration-property-value-no-unknown": [
      true,
-     {
-       "propertiesSyntax": { "top": "| <--foo()>" },
-       "typesSyntax": { "--foo()": "--foo( <length-percentage> )" }
-     }
    ]
  }
}
```

### Changed TypeScript config files to be loaded by Node.js's built-in type stripping

We've changed TypeScript config files, such as `stylelint.config.ts`, to be loaded by Node.js's [type stripping](https://nodejs.org/api/typescript.html#type-stripping) rather than the `typescript` package, which you no longer need to install.

Only erasable syntax is supported. You should update your config to:

- use `import type` for type-only imports
- replace syntax that needs transforming, such as `enum` and `namespace`

For example:

```diff ts
-import { Config } from "stylelint";
+import type { Config } from "stylelint";
```
