# Migrating to 18.0.0

This release contains breaking changes.

## Breaking changes

We've removed:

- support for Node.js less than 22.18.0

### Removed support for Node.js less than 22.18.0

We've removed support for Node.js versions less than 20.19.0, including end-of-life 20.x, to update all our dependencies.

We recommend updating to the latest version of Node.js.
